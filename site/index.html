CISS Advertising Observatory

Explore fossil fuel advertising records, compare companies and publishers, and ask research questions with citations to the underlying sources.

Live Data Live Query GitHub code

This is the static project page. The interactive application runs on Railway.

Current features

  • Company and publisher counts

    Compare advertising volumes and inspect which companies and publishers appear together in the collected records.

  • Interactive source graph

    Select companies, publishers, relationships, or articles to view supporting records and clearly labeled distributions.

  • Dates and historical labels

    Filter the collection by date and explore existing historical labels. These labels are not verified greenwashing conclusions.

  • Records and cited answers

    Read article details and original source links. Ask questions using database tools and retrieval-augmented generation grounded in advertising records.

Collections and sources

The application supports native advertising records and social-media company posts.

  • Native advertising: available for exploration in the live application.
  • Social media: company-post exploration is supported; available records depend on the deployed dataset.
  • CLAIMS integration: validate imported results and read configured classifications with their source evidence.

Counts describe the collected records. Graph relationships reflect their source fields and do not independently establish payment or commercial cooperation.
