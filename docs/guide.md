# User guide

## Data

The Data page has three views: **Overview**, **Relationships**, and **Records**.

1. Select native advertising, social media, or both collections.
2. Set the company, outlet, platform, account, and date filters available for that collection.
3. Check the selected scope before interpreting a chart or exporting records.

**Overview** compares recorded volumes by company and outlet. Matrix cells show counts and lead to their records. Distributions and date charts reflect the same filters.

**Relationships** shows named native-record connections. Select a company or outlet to see its related entities, distribution, and supporting records. A connection reflects stored source fields; it does not establish a contract or editorial endorsement.

**Records** lists the selected collection. Open a title to read stored text and available sources. CSV exports use the current filters.

## Query

Enter a question, choose the collection scope, and select **Generate answer**. The result presents a summary, supporting evidence, and limitations. Counts are calculated from stored records; content answers cite retrieved advertisements.

Use **Search keywords** to browse matching passages without a model call. Generated answers require the configured model service and can incur API charges.

After changing the question or filters, submit again. A displayed answer describes its submitted scope.

## Read evidence

Each result identifies its record, source, and available date. Citations link to supporting material. Technical details expose version and location information when needed.

The website distinguishes original article text, image descriptions, and video transcripts. Derived text is not an original article quotation.

## Interpret the results

- Native-ad counts describe the stored collection, not all advertisements ever published.
- Social records are collected company posts. Company affiliation does not establish paid sponsorship.
- Missing dates and inferred dates remain distinct. Check whether unknown dates are included.
- Historical annotations and automatic CLAIMS results retain their review status.
- Retrieved examples are bounded evidence, not proof that every relevant record was found.
- An unavailable service, missing field, or incomplete source is shown separately from a zero count.
- External findings, when enabled, are separate from collection counts.

Original links and attachment availability vary by record. See [record assets](record_assets.md) for attachment configuration and [the data dictionary](data_dictionary.md) for field definitions.
