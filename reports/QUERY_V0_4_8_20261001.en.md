# Query update 0.4.8

This update adds percentages to the existing database statistics tool. It also corrects the development selftest so an outage, wrong scope, count-only percentage response or incomplete run cannot receive a pass. [Engineering receipt](query_v0_4_8_engineering_20261001.json).

## Current behavior

- Ask for a count, publisher list or source-listed sponsor list. The model selects constrained tools; the database supplies the numbers.
- For a percentage, the target filters select matching records. The denominator remains the current page selection before those targets. Native articles and social posts have separate denominators. Select another scope first when a different denominator is needed.
- The answer shows the percentage, numerator, denominator and scope. An empty denominator is undefined; a collection that has not been loaded is omitted.
- Publisher aliases use actual stored categories. Company spellings and organizational categories remain separate.
- The language check can ignore exact titles from selected evidence. Other quoted generated prose is checked; short or ambiguous text remains inconclusive. This is a language heuristic, not factual verification.
- Budget and rate limits have a distinct public message. Provider errors remain sanitized.
