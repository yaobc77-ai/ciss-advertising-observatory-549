# CLAIMS2 evidence and legacy source discovery

Version 0.4.6 adds read-only CLAIMS2 results to the native Overview, article
detail, Query tools and typed source graph. Category definitions and exact text
evidence retain their taxonomy, run, review and article versions. Selecting an
assignment shows that assignment's NC-to-SC relation and source evidence.
Matching-page JSON exports distinguish page records from filtered totals.

All 37 real saved-result candidates remain on hold. No new real classifications
or source associations have been published. Missing assignments are not
classified negatives.

## Legacy article URLs

The optional maintenance MCP tool `find_claims_source_candidates` first checks
unchanged excerpts against current eligible native text. Local matches avoid a
model call. Otherwise it permits one paid web search and returns up to five
unverified source references. It is hidden by default and excluded from the
ordinary website question tools. It writes only usage accounting.

One actual legacy excerpt was tested. The search cost recorded in the ledger
was **$0.0134298**. It returned related references but did not establish the
original article URL. The result remains unresolved. This is an interface and
accounting check, not a source-recovery benchmark.
